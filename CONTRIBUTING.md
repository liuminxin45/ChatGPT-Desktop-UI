# Contributing

Read [AGENTS.md](AGENTS.md), [design system](docs/design-system/README.md) and [development contract](docs/development/README.md). Use Node 24.19.0, `npm ci`, then `npm run check`. Use `npm run site:build` for the static replica/reference/gallery.

Describe the concrete problem, resulting behavior, compatibility/Host boundaries and meaningful validation in a change. Preserve one implementation owner. Include actual component adoption or a stateful example and generate API docs from code. Keep private content out of public examples/reports. Publishing and consumer upgrades follow the explicit integration request and coordinated release contract.
